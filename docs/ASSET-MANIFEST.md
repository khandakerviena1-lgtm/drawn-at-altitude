## Film grading
All footage is graded at display time through the `--film-grade` token (`saturate .87 · contrast 1.05 · sepia .13 · hue-rotate −9° · brightness 1.02`). It pulls the proxy's digital cyan back and gives the rock mineral warmth — ochre, sand, grey-violet — so the film marries the paper and the watercolour. The shift is deliberately small and warmth-weighted so the river blues survive. **This is a CSS treatment, not a re-encode**: the source files are untouched, and the grade must be re-judged (and probably reduced) against a proper 1080p/4K master, since it is currently compensating for a 480p proxy's oversaturation. `ArtistVision` animates its own `saturate()` inline and therefore overrides this token — reconcile the two when that scene is rebuilt.
